# SLAM Drone for Disaster Management

Autonomous quadcopter that localises itself, maps its surroundings and avoids obstacles without GPS. Developed in an AirSim / Unreal Engine simulation of the IIIT Sri City campus, with models benchmarked on an NVIDIA Jetson Nano (the planned onboard computer).

Additional project at IIIT Sri City: *Adaptive Mobile IoT Networks Using UAV-Assisted Weighted Federated Learning, Multi-Sensor SLAM, and Edge AI for Disaster Management*.

**Team:** Mukunth Parthasarathy, Mithun Vijay, Koda Adam, Sharath C
**Mentors:** Dr. Raja Vara Prasad, Dr. Pavan Kumar BN

## Status

Work in progress. All results so far are from simulation.

## Adding your code

- Put your code in a folder named after your part (for example `mapping/`, `perception/`, `control/`, `jetson/`).
- Add a few lines at the top of each folder's README saying what the code does and how to run it.
- Do not upload large files (recorded flights, point clouds, datasets, videos). Put them on Drive and link them instead.
- Do not upload passwords, API keys or personal paths you don't want public.
